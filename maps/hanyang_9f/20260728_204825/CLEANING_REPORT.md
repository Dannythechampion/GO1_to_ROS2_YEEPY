# 한양대 9층 점유 지도 정리 보고서

## 결론

Nav2에는 원본 대신 `slam_toolbox/hanyang_9f_cleaned.yaml`을 사용하는 것을
권장한다. 원본 `hanyang_9f.pgm`과 pose graph는 수정하지 않았다.

정리본은 검은색 점유 셀(벽/장애물)을 새로 만들거나 삭제하지 않는다.
투명·반투명 문을 통과한 것으로 보이는 얇은 방사형 자유공간만 회색
미확인 영역으로 되돌렸다. 따라서 관측되지 않은 공간을 주행 가능하다고
과신하는 위험을 줄이면서, 반복 관측된 복도와 방의 넓은 자유공간은 남긴다.

## 적용 기준

- 해상도: 0.05 m/px
- 자유공간 지지 반경: 2 px (0.10 m)
- 원본 자유 셀: 51,191
- 유지한 자유 셀: 43,453
- 미확인으로 되돌린 셀: 7,738 (15.12%)
- 점유 셀 변경: 0
- 원본/정리본 크기: 409 x 586 px

`hanyang_9f_cleaning_overlay.png`에서 주황색이 미확인 영역으로 되돌린
셀이다.

## 수동 편집이 필요한 경우

얇은 빗살 잡음은 자동으로 구분할 수 있지만, 폭이 넓게 비친 유리문과 실제로
열린 출입구는 2D LiDAR 결과만으로 완전히 구분할 수 없다. 실제 출입 가능
여부까지 반영하려면 현장에서 문 위치를 확인한 뒤 해당 구간만 수동으로
막아야 한다.

수동 편집 시에는 원본을 덮어쓰지 말고 정리본의 복사본을 편집한다.

- 확실한 유리벽/고정문: 검은색(0)으로 벽을 연결
- 불확실한 구역: 회색(205) 유지
- 실제로 주행해 확인한 열린 통로만 흰색(254) 유지

Nav2용 지도에서는 미확인 공간을 흰색으로 칠하지 않는 것이 안전하다.

## 재생성

```bash
python3 tools/clean_occupancy_map.py \
  --input maps/hanyang_9f/20260728_204825/slam_toolbox/hanyang_9f.pgm \
  --output maps/hanyang_9f/20260728_204825/slam_toolbox/hanyang_9f_cleaned.pgm \
  --preview maps/hanyang_9f/20260728_204825/hanyang_9f_cleaning_overlay.png \
  --radius-px 2 \
  --min-component-px 12
```
